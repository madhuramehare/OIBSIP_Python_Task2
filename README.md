### Objective
To develop a secure password generator that creates strong passwords based on user-defined length and character types.

### Steps Performed
1.Created a Tkinter GUI.
2.Added length and character selection.
3.Generated passwords using `secrets`.
4.Added strength indication.
5.Clipboard copying.
6.Ambiguous-character exclusion.
7.Last-five-password history.

### Tools Used
Python – Main programming language
Tkinter – GUI development
secrets – Secure random password generation
string – Character sets
pyperclip – Clipboard integration
VS Code – Development environment

### Outcome
Successfully developed a user-friendly application that generates secure, customizable passwords and improves password security through strong character combinations.
